# xhs-live-filter

小红书 PC Web 网页端直播聚焦与互动发现增强 Userscript。

在直播广场与探索信息流中，通过主播事实归一化、用户动态过滤策略与就地内容匹配，帮助用户快速聚焦目标主播，并在不破坏原生网格布局的前提下提供直观视觉反馈与防风控保护。

---

## 🎯 核心功能特性

1. **就地关键词聚焦 (Local Keyword Match)**：
   - 支持对直播标题（`title`）与主播昵称（`nickname`）执行大小写不敏感的普通子串匹配。
   - 匹配卡片保留展示，未匹配卡片在当前视图中折叠占位，清空关键词即时全量恢复。
   - 严格遵循 **ADR-0001**：保留原生 DOM 几何空间与节点完整性，不破坏原生 CSS Grid 流或无限滚动加载。

2. **粗粒度 IP 属地偏好与徽标增强 (Coarse Region Priority)**：
   - 视口内卡片通过公开 Profile SSR 异步获取公开粗粒度 IP 属地标签（境内省/自治区/直辖市级，境外国家/地区级）。
   - 默认设置偏好属地为 `['广东']`。命中偏好的卡片高亮标注为 `🎯 广东`（`TARGET`），非偏好卡片标注为 `⚪ [省份]`（`CANDIDATE`）。
   - 严格遵循 **ADR-0002**：属地不符绝不产生硬排除（Fail-Open）。

3. **两级缓存体系 (Two-tier Cache)**：
   - L1 内存缓存 + L2 Tampermonkey 持久化存储，默认 24 小时 TTL，容量保护约 2000 项。
   - 缓存命中时 0 网络请求，429 或异常响应绝不写入缓存。

4. **性别校准门禁 (Gender Calibration Gate)**：
   - 遵循 **ADR-0003** 与 **ADR-0006**：原始代码与领域事实彻底解耦。
   - 当前版本默认运行在 **`UNCALIBRATED`** 状态，所有主播性别归一化为 `unknown` 并全面 **Fail-Open**。
   - 绝不通过主播头像、外貌、声线或直播内容臆断性别。

5. **视口感知调度与单次手动探针熔断 (Safety Scheduling & Manual Recovery)**：
   - 调度器基于 `IntersectionObserver`（200px 缓冲区）调度，严格限制并发 `<= 2`，滚出视口卡片主动丢弃。
   - 遇到 HTTP 429 或验证码立即进入 `PAUSED` 熔断状态，胶囊黄色告警。
   - **唯一恢复路径为用户手动点击 `[恢复]`** 发起严格单次探测（exactly one probe），绝无后台自动重试风暴。

## 📥 安装指南

### 前置要求
浏览器需安装 Tampermonkey（油猴）扩展插件。

### 安装步骤
1. 点击以下链接直接安装最新版本：
   - **[一键安装 / 下载链接](https://raw.githubusercontent.com/carllx/xhs-live-filter/main/dist/xhs-live-filter.user.js)**
2. Tampermonkey 会自动弹出安装确认窗口，点击 **“安装”**。
3. 打开或刷新 [小红书网页端](https://www.xiaohongshu.com/)，页面右上角将出现悬浮胶囊：`🎯 直播过滤 (0/0)`。

## 🛠️ 使用说明

1. **关键词过滤**：
   - 点击右上角悬浮胶囊展开过滤面板。
   - 在“内容关键词”输入框中输入词汇（如“艺术”、“手作”），页面卡片即时响应。
   - 点击“清空”按钮恢复全部卡片展示。
2. **偏好属地设置**：
   - 在面板“偏好属地”中配置所需省份（如 `广东, 上海`），卡片徽标即时刷新。
3. **隐藏已排除卡片**：
   - 勾选“隐藏已排除主播”，被排除卡片将被占位隐藏；默认取消勾选时，被排除卡片以灰度半透明保留在原有几何占位。
4. **风控恢复**：
   - 若短时间内浏览过多卡片触发平台限流，胶囊将显示 `⚠️ 已暂停 · 风控保护`。
   - 稍作等待后，点击警告框中的 `[恢复]` 按钮发起单次恢复探测。

## ⚠️ 能力边界与真实性原则 (Capability Truth)

- **地域能力边界**：当前仅支持小红书公开 profile 的 `ipLocation`（省级/国家级粗粒度属地），不支持普通城市级（如“广州”“深圳”）。
- **年龄能力**：平台公开 Profile 数据中无可靠年龄字段，UI 显式置灰禁用（Disabled），评估判定严格 Fail-Open。
- **性别校准**：未取得平台确凿公开核验证据前，系统保持 `UNCALIBRATED`，杜绝任何主观推断。
- **更新契约**：脚本提供合法的 `@version`、`@updateURL` 与 `@downloadURL`。是否自动下载或提示更新遵循用户本地 Tampermonkey 的设置与权限。
