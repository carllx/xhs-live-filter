# 0001. 保留原生 DOM 几何结构与非破坏性视觉处理

## 决策背景与核心决定

小红书 PC Web 网页版直播列表采用无限滚动瀑布流布局。若直接使用 `display: none` 强行移除已排除卡片或重排 DOM 顺序，将破坏浏览器的几何排版与滚动高度测量，诱发列表死循环滚动请求或排版塌陷。

我们决定在 v0.1 中完全保留原生 DOM 节点的占位结构与次序，仅通过样式层调整视觉权重：
- **TARGET**：施加醒目边框高亮与确定事实徽标；
- **CANDIDATE**：保留卡片原貌并轻度降权（opacity 0.70–0.85）；
- **EXCLUDED**：采用极度弱化（灰度化 + opacity 0.08–0.15 + pointer-events: none），仅在用户主动开启“隐藏已排除”且经过安全验证后方允许物理折叠。

## 权衡与考量 (Trade-offs)

放弃了“彻底清理干净界面、消除空白占位”的激进做法，换取了绝对的页面原生交互稳定性与反反爬抗干扰能力。
