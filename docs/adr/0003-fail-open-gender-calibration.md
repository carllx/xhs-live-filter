# 0003. 性别代码现场校准与故障安全放行状态机

## 决策背景与核心决定

小红书网页端返回的 `gender` 字段为原始数值（如 0、1、2），其对应的 normalized gender label 枚举映射尚未在真实环境下完成对齐验证。若在代码中主观臆断硬编码，将造成严重的误排除（例如将女性错误标记为男性并一票否决）。

我们决定引入显式的性别校准状态机：
- 系统初始处于 `UNCALIBRATED`（未校准）状态；
- 在 `UNCALIBRATED` 状态下，分类器执行严格的 **Fail-Open（故障安全放行）** 策略：所有 `0 / 1 / 2 / missing` 均视为 `unknown`，一律不触发男性硬排除，保证 0 误杀；
- 保留原始数据 `rawGender`，在卡片上可显示轻量校准调试标记（如 `性别码 0`），并在 Console 中对首次出现的原始值打印去重样本；
- 仅在真实样本现场校准完成后，切换至 `CALIBRATED` 状态，方正式激活基于性别的硬排除门禁。

## 权衡与考量 (Trade-offs)

牺牲了 v0.1 最初版本在尚未校准阶段的性别排除能力，彻底消除了由于平台字段语义未知而产生错杀合法目标主播的不可逆风险。
